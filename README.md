# Русская Вавилонская Библиотека (Library of Voronezh)

Цифровая реализация легендарного рассказа **Хорхе Луиса Борхеса «Вавилонская библиотека»** (1941) на русском языке.

Бесконечное хранилище текстов, основанное на обратимой детерминированной математической биекции над $\mathbb{Z}_{34^{3200}}$. Каждая книга, каждая мысль, каждое слово из 34 символов русского алфавита уже находится на определённой полке.

---

## 🚀 Быстрый запуск

### Вариант 1: В один клик (Windows)
Просто запустите файл **`run.bat`** в корневой папке проекта. Он автоматически:
1. Запустит бэкенд на `http://127.0.0.1:8000`.
2. Запустит фронтенд на `http://127.0.0.1:5173`.
3. Откроет браузер по адресу `http://127.0.0.1:5173/`.

---

### Вариант 2: Запуск вручную через консоль

#### 1. Запуск Бэкенда (Python / FastAPI)
Откройте первый терминал:
```bash
cd backend
pip install -r requirements.txt   # (при первом запуске)
python -m uvicorn main:app --port 8000 --reload
```
*API будет доступно по адресу:* [http://127.0.0.1:8000](http://127.0.0.1:8000) (документация Swagger: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)).

#### 2. Запуск Фронтенда (React + Vite)
Откройте второй терминал:
```bash
cd frontend
npm install                      # (при первом запуске)
npm run dev
```
*Интерфейс будет доступен по адресу:* [http://127.0.0.1:5173](http://127.0.0.1:5173).

---

## 🧪 Запуск тестов

Для проверки алгоритма биекции и эндпоинтов API:
```bash
cd backend
python test_backend.py
```
*(Все 14 тестов отрабатывают за ~0.13 секунды).*

Для сборки фронтенда:
```bash
cd frontend
npm run build
```

## 🏛 Структура проекта

- **`backend/`**
  - `algorithm.py` — алгоритм биекции (обратимый аффинный шифр над $\mathbb{Z}_{34^{3200}}$), расширенный алгоритм Евклида, 4 режима поиска, генерация заголовков томов.
  - `main.py` — FastAPI сервер: `/api/search`, `/api/browse`, `/api/shelf`, `/api/random`, `/api/stats`, `/api/health`.
  - `dictionary.py` — частотный словарь русских слов для режима «Среди случайных слов».
  - `test_backend.py` — модульные тесты корректности биекции и API.
- **`frontend/`**
  - `src/components/SearchPage.tsx` — поиск с литературными пресетами (Мандельштам, Платонов, Пушкин, Достоевский, Борхес).
  - `src/components/BrowsePage.tsx` — 2D-план зала, полки шкафа, интерактивные 32 книги с тиснением.
  - `src/components/ReaderPage.tsx` — чтение страницы (4 темы: Cosmic, Parchment, Matrix, Archive; режимы: сетка 40×80 и поток текста; голосовой синтез речи TTS; экспорт).
  - `src/components/BookmarksModal.tsx` — управление закладками, заметками и историей поисков.
  - `src/components/AboutPage.tsx` — математическое описание, литературный контекст Воронежа, калькулятор $34^N$.
  - `src/utils/audio.ts` — атмосферный звук библиотеки на Web Audio API и шелест страниц.
